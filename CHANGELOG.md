# Changelog

## 0.12.3-alpha.1 — consolidated, unreleased candidate

Implements the 0.11.7–0.12.3 work packages together, without fabricating intermediate
releases. Adds server policy and per-player preferences, bounded versioned payloads,
client/server separation, authoritative inventory sorting, server activation of
Timber/Farmer, policy-aware grave/tool behavior, UI locks, one distribution artifact,
CI target matrix and test-gated draft releases. Existing 0.11.6 visuals, defaults,
notes format and compatibility adapters are retained.

Real Minecraft compilation and runtime acceptance are pending; see
`docs/IMPLEMENTATION_STATUS.md`. Pure logic and static checks are recorded separately.
